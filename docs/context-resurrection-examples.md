## Example 2: Event-Based Resurrection with Keywords

**Request:**
```bash
curl -X POST https://your-app.onrender.com/api/context/resurrect \
  -H "Content-Type: application/json" \
  -d '{
    "date": "2024-01-10",
    "event_description": "When I decided to pursue the AI startup idea",
    "keywords": ["startup", "AI", "funding", "equity"],
    "window_days": 14
  }'
```

This will:
1. Search ±14 days around January 10, 2024
2. Extract additional keywords from "decided pursue AI startup idea"
3. Boost relevance for items containing: startup, AI, funding, equity, decided, pursue
4. Generate a narrative focused on that decision

## Example 4: Before/After Comparison

**Request:**
```bash
curl -X POST https://your-app.onrender.com/api/context/compare \
  -H "Content-Type: application/json" \
  -d '{
    "date1": "2023-10-01",
    "date2": "2024-01-01",
    "window_days": 14
  }'
```

**Sample Response:**
```json
{
  "comparison": {
    "date1": "2023-10-01T00:00:00.000Z",
    "date2": "2024-01-01T00:00:00.000Z",
    "window_days": 14,
    "changes": {
      "total_items": 35,
      "high_relevance": 12
    },
    "by_category": {
      "briefings": { "before": 15, "after": 28, "change": 13 },
      "expenses": { "before": 45, "after": 52, "change": 7 },
      "jobs": { "before": 8, "after": 2, "change": -6 },
      "ideas": { "before": 2, "after": 7, "change": 5 },
      "resources": { "before": 5, "after": 12, "change": 7 },
      "pitches": { "before": 0, "after": 3, "change": 3 }
    }
  },
  "before": { "...full context for October..." },
  "after": { "...full context for January..." }
}
```

**Insight:** Job tracking dropped (-6), but ideas (+5), resources (+7), and pitches (+3) increased. This suggests a shift from job hunting to entrepreneurial exploration.

## Use Case: Natural Language Integration

You can build a natural language interface on top of Context Resurrection:

**User says:** "What was happening in my life when I bought that expensive dinner in December?"

**Your system:**
1. Extracts date hint: "December" → searches recent December
2. Extracts keywords: "expensive", "dinner"
3. Calls `/api/context/resurrect` with those parameters
4. Returns the narrative snapshot

**User says:** "Compare my activity before and after I started the new job"

**Your system:**
1. Finds job start date from jobs table
2. Calls `/api/context/compare` with dates before/after
3. Generates insight summary from comparison
