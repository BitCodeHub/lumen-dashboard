# Meeting Prep Autopilot API

> 🤖 **Your AI Chief of Staff** - Generates comprehensive meeting prep briefings automatically

The Meeting Prep Autopilot analyzes your data, researches the person/company, and creates a thorough briefing so you walk into every meeting prepared.

---

## Quick Start

```bash
# Generate a meeting prep briefing
curl -X POST http://localhost:3000/api/meetings/prep \
  -H "Content-Type: application/json" \
  -d '{
    "person_name": "Jane Smith",
    "company": "Acme Corp",
    "meeting_topic": "Partnership discussion",
    "date": "2024-02-15T14:00:00Z",
    "role": "VP of Engineering"
  }'
```

## Endpoints

### POST `/api/meetings/prep`

Generate a comprehensive meeting prep briefing.

#### Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `person_name` | string | ✅ Yes | Name of the person you're meeting with |
| `company` | string | No | Company/organization they work for |
| `meeting_topic` | string | No | Purpose or topic of the meeting |
| `date` | string (ISO 8601) | No | Meeting date and time |
| `role` | string | No | Their job title/role |
| `save` | boolean | No | Save to briefings (default: true) |

#### Example Request

```json
{
  "person_name": "Sarah Chen",
  "company": "TechVentures",
  "meeting_topic": "Series A funding discussion",
  "date": "2024-02-20T10:00:00-08:00",
  "role": "Managing Partner"
}
```

#### Example Response

```json
{
  "id": 42,
  "briefing": {
    "type": "meeting-prep",
    "title": "Meeting Prep: Sarah Chen @ TechVentures - 2/20/2024",
    "content": "# Meeting Prep: Sarah Chen @ TechVentures\n\n...",
    "summary": "Meeting prep for Sarah Chen at TechVentures about \"Series A funding discussion\". Found 3 relevant items in your history.",
    "tags": ["meeting-prep", "techventures", "topic:series"],
    "metadata": {
      "person_name": "Sarah Chen",
      "company": "TechVentures",
      "meeting_topic": "Series A funding discussion",
      "meeting_date": "2024-02-20T10:00:00-08:00",
      "role": "Managing Partner",
      "history_found": {
        "briefings": 2,
        "expenses": 1,
        "jobs": 0,
        "ideas": 0
      },
      "generated_at": "2024-02-15T12:00:00.000Z"
    }
  },
  "message": "Meeting prep generated successfully",
  "saved": true
}
```

### GET `/api/meetings/prep`

List all meeting prep briefings.

#### Query Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `limit` | number | 20 | Maximum results to return |
| `upcoming` | boolean | false | Only show preps for upcoming meetings |

#### Example

```bash
curl "http://localhost:3000/api/meetings/prep?limit=10"
```

---

### GET `/api/meetings/prep/search`

Search your history for a person/company without creating a briefing.

#### Query Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `person_name` | string | One of these | Person to search for |
| `company` | string | required | Company to search for |

#### Example

```bash
curl "http://localhost:3000/api/meetings/prep/search?person_name=John&company=Acme"
```

#### Response

```json
{
  "person_name": "John",
  "company": "Acme",
  "found": {
    "briefings": 2,
    "expenses": 5,
    "jobs": 1,
    "ideas": 0,
    "total": 8
  },
  "history": {
    "briefings": [...],
    "expenses": [...],
    "jobs": [...],
    "ideas": [...]
  }
}
```

## Briefing Structure

Each generated briefing includes:

### 1. 📅 Meeting Details
- Date, time, and countdown
- Suggested agenda breakdown

### 2. 👤 Person Background
- Name, company, role
- Level detection (executive, manager, individual, etc.)
- Tips for researching them

### 3. 🏢 Company Intel
- Company information
- Any job listings you've tracked from them
- Relevant notes from your data

### 4. 📜 Your History
- **Relevant Briefings** - Past notes mentioning them
- **Related Expenses** - Meals, meetings, etc.
- **Related Ideas** - Projects/pitches involving them

### 5. 🎯 Talking Points
- Topic-specific questions
- Role-appropriate questions
- Your goals for the meeting

### 6. ⚠️ Watch Out For
- Role-specific gotchas
- General tips
- Notes from previous interactions

### 7. ✅ Pre-Meeting Checklist
- Research reminders
- Prep tasks
- Time blocking suggestions

## Data Sources Searched

The Meeting Prep Autopilot searches these tables in your Lumen database:

| Table | What it finds |
|-------|---------------|
| `lumen_briefings` | Past notes/briefings mentioning the person or company |
| `lumen_expenses` | Meals, meetings, transactions with them |
| `lumen_jobs` | Job listings from that company |
| `lumen_ideas` | Projects/pitches related to them |

| Level | Detected Keywords |
|-------|------------------|

| Director | Director, VP, Vice President, Head of, SVP |
| Manager | Manager, Lead, Team Lead, Supervisor |
| Individual | Engineer, Developer, Designer, Analyst, Specialist |
| Sales | Sales, Account Executive, AE, BDR, SDR |
| Investor | Investor, VC, Venture, Angel, Capital, Fund |

## Best Practices

### 1. Include as much context as possible
```json
{
  "person_name": "John Smith",
  "company": "Acme Corp",
  "meeting_topic": "Q1 planning review",
  "date": "2024-02-15T09:00:00Z",
  "role": "Director of Engineering"
}
```

### 2. Run preps 24-48 hours before meetings
This gives you time to do additional research.

### 3. Use the search endpoint first
Check what history exists before generating the full briefing.

### 4. Track all meetings
Log expenses and notes for everyone you meet - the system gets smarter with more data.

## Error Handling

| Status | Error | Solution |
|--------|-------|----------|
| 400 | `Missing required field: person_name` | Include `person_name` in request |
| 400 | `Person name too short` | Name must be 2+ characters |
| 500 | `Failed to generate meeting prep` | Check server logs for details |

## Integration Ideas

### Calendar Integration
Automatically generate preps 24h before each calendar event:
```javascript
// Pseudo-code for calendar trigger
calendarEvents.forEach(event => {
  if (event.startsIn('24 hours') && !hasPrep(event)) {
    generateMeetingPrep({
      person_name: event.attendees[0].name,
      company: event.attendees[0].company,
      meeting_topic: event.title,
      date: event.start
    });
  }
});
```
